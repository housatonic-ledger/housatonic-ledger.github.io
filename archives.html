A New Digital Index Opens Decades of Local History

An ongoing cataloguing effort brings photographs, paper files and decades of regional history into a single searchable collection.

By Evelyn Carter   |   October 2026   |   5 min read

When records are kept in several buildings and described under different systems, even a simple local-history question can take days to answer. An emerging digital index aims to make those scattered collections easier to navigate.

The work involves much more than scanning documents. Volunteers and archivists must identify dates, confirm place names and connect loose photographs to the correspondence that originally accompanied them.

The resulting index does not replace the original materials. Instead, it provides a route into them: a reference number, a brief description and, where possible, an indication of where the physical item can be consulted.

Early batches include property files, neighborhood photographs, oral-history notes and newsletters spanning several decades. Some entries remain provisional until another source confirms their dates.

A small group of imported records has proved difficult to reconcile. The inventory lists four file references without corresponding location data: 68-017, 72-004, 73-041 and 74-019.

The staff copy refers to a problem with the index restoration key. On one line, a number is written as 7-15-4, without further explanation.

The line beneath it contains an unfamiliar sequence: souophrzhogfualtu. The letters are preserved here as entered in the source.

A follow-up search returns one result. A second search returns none. Both searches use the same reference number.

RESTORATION RECORD 7-15-4 / RECOVERED PATH souophrzhogfualtu / STATUS INCOMPLETE

The index is not looking for a document. The index is looking for an address.

THE RECORD WAS NEVER LOST. THE RECORD WAS BURIED. THE RECORD WAS BURIED WITH THE HOUSE.

SEARCH COMPLETE. SEARCH COMPLETE. THE RECORD HAS FOUND YOU.
